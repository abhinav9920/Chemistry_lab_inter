Isothermal relation

What is happening?

For an ideal gas, internal energy depends only on temperature. Because temperature remains constant, ΔU = 0 and heat exchanged balances the work.

Comparison of the Four Processes

ProcessConstant quantityIdeal-gas relationHeat and workInternal energy
IsothermalTemperaturePV = constantq = −wΔU = 0
AdiabaticHeat exchange is zeroPVγ = constantq = 0ΔU = w
IsochoricVolumeP/T = constantw = 0ΔU = q
IsobaricPressureV/T = constantw = −PΔVΔU = q + w

Sign convention used throughout: ΔU = q + w. Heat absorbed by the system is positive. Work done on the system is positive; work done by an expanding gas is negative. The adiabatic model uses γ = 1.40 and CV = R/(γ−1).
