# Telangana Intermediate Chemistry Lab

## Simulation: Heat, Work & Energy Transfer

Path: `second-year/thermodynamics/heat-work-energy/`

A touch-friendly conceptual simulation for introducing thermodynamics through a gas-cylinder model.

### Classroom use
1. Ask students to predict what happens when heat is supplied with the piston locked.
2. Try expansion with no heat input.
3. Allow both heat transfer and expansion.
4. Discuss the chemistry sign convention for work.
5. Only after the exploration, introduce the first-law relationship.

### Important
The displayed numerical values are illustrative. This model is intended for conceptual classroom discussion, not as a precision thermodynamics calculator.
